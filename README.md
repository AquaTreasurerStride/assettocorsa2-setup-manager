## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Setup Library** | Save and organize setups per car and track combination |
| **Setup Compare** | Side-by-side comparison of two setups with diff highlighting |
| **Session Log** | Log sessions with weather, lap times and setup used |
| **Delta Tracker** | Track lap time improvements across sessions with the same setup |
